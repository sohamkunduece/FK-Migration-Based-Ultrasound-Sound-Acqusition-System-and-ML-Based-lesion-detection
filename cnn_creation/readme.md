The dataset used here is “75 \- angle Phantom” dataset.  
Due to storage issues, only 40 files were used which were used for creating this CNN. The cnn follows type-1 format as we talked about in “approach section” of the project readme.  
The CNN takes input directly from the acquisition setup.  
The header file remains the same.  
The model and the confusion matrix can be found under model.
It is to be noted that 75-angle phantom dataset was mostly used for creating the cnn. Since the dataset images produce are all same to represnt the phantoms, thecnn has a problem of overfiting.The purpose of cnn is to act as simple "AI Interface" for the pipeline as stated in the challenge cataloge.
